# Laundry Legends 1.0.0 — Release Notes

**Release candidate:** 1.0.0
**Platform:** Windows 64-bit
**Engine:** Unity 6.0 LTS (`6000.0.64f1`), Universal Render Pipeline

## Highlights

- Run a neighbourhood laundromat: take orders, wash, dry, fold and hand back wrapped laundry.
- Ten-order queue with a ten-slot counter rack, customer patience and exactly-once payment.
- Three consumable shelves (detergent, fragrance, plastic) with stock blocking and restock.
- A 24-hour clock with day skip and 30-day rent/electricity/water bills.
- Discover a concealed back room and turn it into an arcade: attract mode, playable cabinets, upgrades, expansion and reputation.
- Audio buses and pause-menu volume controls; automatic save/load with corrupt-file recovery.

## Controls

WASD move · Mouse look · E interact · Q drop · U purchases · B bills · N next day · M map · Esc pause

## Known issues

See `KNOWN_ISSUES.md`. Remaining items are post-1.0 polish, external-board/Unreal work, and art placeholders.

## Install

Unzip the release folder and run `LaundryLegends.exe`. Saves live in
`%USERPROFILE%\AppData\LocalLow\LaundryLegends\Laundry Legends\laundry-legends.save.json`.
