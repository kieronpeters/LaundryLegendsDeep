# ArtSource

Editable source files for Laundry Legends assets. This folder is not a Unity runtime folder and is not included in builds.

## Layout

- `Blender/` - `.blend` files and generator scripts.
- `Decals/` - CC0 grunge/decal overlays and paper notices (see `Decals/README.md`).
- `Exports/` - FBX/glTF exports before or alongside Unity import.
- `Licenses/` - source URLs, authors, license text, and attribution notes.
- `References/` - public-domain style references and briefs.
- `Textures/` - 4K CC0 PBR source sets (ambientCG). See `Textures/README.md`
  for provenance, verification, and Unity import guidance. Not a Unity folder.

## First asset

`Blender/create_basket.py` builds a low-poly open laundry basket and exports `Exports/LaundryBasket.fbx`. The editable `Blender/LaundryBasket.blend` is generated by the script.

Run:

```powershell
blender --background --python ArtSource/Blender/create_basket.py
```

## Rules

- Keep the exported FBX and the `.blend` in sync.
- Apply transforms before export; 1 Blender unit = 1 meter.
- Do not store downloaded third-party packs here without a license record in `Licenses/` and `ASSET_INVENTORY.md`.
- Do not commit paid, account-restricted, or AI-generated assets.
