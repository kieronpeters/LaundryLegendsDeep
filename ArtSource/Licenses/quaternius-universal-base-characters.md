## Caveat on provenance

This is a **mirror**, not the author's own download. The licence (CC0) is
verified from the author's pages, not from the mirror; the mirror is only the
transport. CC0 grants redistribution rights, so the mirror copy is legally the
same asset. Still, if the project ever wants a pristine copy, re-download the
122 MB Standard zip from itch.io on a machine where the checkout works and
diff the file hashes.

## Verdict for Laundry Legends

Technically the strongest of the three candidates (65 bones, clean
`pelvis`/`spine_01`/`upperarm_l` naming, exactly 1.82 m at import scale 1,
T-pose, 65 vertex groups) but **not usable as-is**: the free Standard edition
only ships the *Superhero* bodies, which are muscular adult figures in
underwear with no clothing. The Regular and Teen bodies and all outfits are in
the paid Source edition or the separate `Modular Character Outfits` pack. See
`ArtSource/Notes/character-candidates.md`.
